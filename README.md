# APA 7 — Nombres completos (CSL para Zotero)

Este repositorio contiene un estilo CSL que muestra **nombres completos** (no iniciales) en **citas en el texto** y en la **bibliografía**.

## Archivos clave
- `apa-annotated-bibliography-full-given-names-IN-TEXT.csl` → Nombres completos en **texto** y **bibliografía**.
- `apa-annotated-bibliography-full-given-names.csl` → Nombres completos **solo** en bibliografía (opcional).

> Nota: Este estilo **no es APA canónico** (APA exige iniciales). Úsalo solo si tu institución/rúbrica lo requiere.

## Instalación en Zotero
1. Descarga el `.csl` deseado.
2. Abre **Zotero → Preferencias → Citar → Estilos** y pulsa **“+”**.
3. Selecciona el archivo `.csl` y confirma.
4. En tu documento (Word/LibreOffice/Google Docs), elige el estilo en **Document Preferences** y pulsa **Refresh**.

## Compatibilidad
- Zotero 6/7, Juris-M y cualquier procesador CiteProc-JS compatible.
